🎬 Movie Explorer App

A simple web app to search and explore movies.

## 🚀 Features

* Search movies
* View details
* Watch trailers
* Clean UI

## 🛠️ Tech Used

* HTML
* CSS
* JavaScript

## 📌 How to Run

1. Download the project
2. Open index.html in browser

## 🔥 Future Plans


* Better UI
* Add favorites
* Dark mode
